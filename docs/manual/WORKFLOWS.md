# 常见操作流程

> 本文回答：常见操作怎么做，按顺序走一遍。控件名称与源码一致。
> 功能全表见 [FEATURES.md](FEATURES.md)，构建安装见 [INSTALL.md](INSTALL.md)，出问题见
> [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。本文假定程序已在宿主里运行。

## 1. 前提

程序必须从宿主启动（`mfmath-host-rust.exe`）。浏览器预览没有引擎桥，计算页会显示「浏览器预览
（无引擎）」，结果对话框会显示「计算功能待接入引擎」。入口只有两处：左侧导航栏与顶栏按钮行。

## 2. 算一道题

以代数化简为例：

| 步骤 | 操作 | 界面上的文字 |
| --- | --- | --- |
| 1 | 点侧栏「计算模式」→「代数计算」 | 进入 `/calc/algebra` |
| 2 | 在输入框写 `x^2 + 2*x + 1` | 占位符「输入表达式，如 x^2+3*x-1」 |
| 3 | 在模式下拉选「化简」 | 下拉内容为代数页的 59 个模式 |
| 4 | 点「计算结果」 | 计算中按钮变为「计算中…」 |
| 5 | 看结果对话框 | 结果用 KaTeX 排版 |

结果对话框底部有四个按钮：「查看步骤」「复制结果」「复制 JSON」「关闭」。「复制结果」给出可读
文本，「复制 JSON」给出引擎原始信封。

引擎命令行对照（不起宿主）：

```powershell
& MF_Mathematics\build\bin\Release\probe_call.exe simplify_polynomial '{"expr":"x^2 + 2*x + 1"}'
# {"isError":false,"value":"(x + 1)**2"}
```

### 需要参数的模式

有些模式（如「梯形法则」「某点导数」）需要额外参数。选这类模式点「计算结果」时，会先弹出
「输入参数 — 模式名」框，逐格填参数，底部是「取消」与「计算」。输入框可以留空，参数在弹窗里收。

缺必填参数时，界面会拒绝计算并写明缺哪个参数，而不是用默认值算出错误结果。

## 3. 画一张图

以 2D 函数绘图为例：

| 步骤 | 操作 | 界面上的文字 |
| --- | --- | --- |
| 1 | 点侧栏「绘图模式」→「2D 函数绘图」 | 首次进入默认一行 `y=x^2` |
| 2 | 在表达式行写 `sin(x)` | 占位符「输入表达式，如 y=x^2 或 cosx」 |
| 3 | 需要多条曲线时点「＋ 添加表达式」 | 行数超过 1 才出现行内删除按钮 |
| 4 | 画布上滚轮缩放、按住拖动平移 | 右上角浮动按钮控制视图 |

右侧浮动按钮：「放大」「缩小」「缩放到适应」「重置视图」「导出图片（PNG，2 倍像素）」
「切换为极坐标网格」「隐藏网格」。点「导出图片」会弹系统保存对话框，结果写进页面状态行。

表达式里出现自由参数（如 `a*sin(b*x)`）时，左栏出现「参数」区与滑块。

## 4. 用 AI 分步讲解

先配置，再使用。

| 步骤 | 操作 |
| --- | --- |
| 1 | 点侧栏底部「设置」→ 左列「AI」 |
| 2 | 打开「启用 AI」开关 |
| 3 | 填「API Base」与「默认模型」，点预设按钮可同时填入 |
| 4 | 在「API Key」粘贴密钥并保存 |
| 5 | 点「测试连接」验证 |

配置好后，在计算结果对话框点「查看步骤」，请求会预填并自动发出，AI 抽屉打开，收尾后自动弹出
分步显示。也可以顶栏点「AI」直接提问。

分步显示里的每一步都是这一轮 AI 调引擎的记录，显示函数名、参数、完整结果与耗时。失败的一步
标红保留。数值来自引擎，不是模型自己写的。

## 5. 用函数工具箱调一个函数

入口：侧栏「工具」→「函数工具箱」。

| 步骤 | 操作 |
| --- | --- |
| 1 | 在搜索框输函数名或模块名过滤 |
| 2 | 点左侧列表中的一个函数 |
| 3 | 右侧按参数表填值，标出「必填」「可选」 |
| 4 | 点「调用引擎」 |
| 5 | 结果区显示引擎原始 JSON |

矩阵、数组类参数要填 JSON 真值，如 `[[1,2],[3,4]]`。慢函数可勾「强制后台」走后台通道。

## 6. 用控制台跑程序

入口：侧栏「工具」→「控制台」。

| 步骤 | 操作 |
| --- | --- |
| 1 | 在「组件」区点 Python 或 C++ 一行的「安装」 |
| 2 | 装好后语言下拉出现对应选项（C++ 只在装好后出现） |
| 3 | 选语言与示例，或直接写代码 |
| 4 | 点「运行 ▷」 |

运行中按钮变「终止 ■」。右侧显示退出码、耗时与输出。每次运行都是新进程，变量不跨次保留。
Python 经 `mfmath` 调引擎，C++ 经导入库调同一引擎，界面不算数学。

## 7. 迁移设置与工作区

工作区与设置迁移都在「设置 → 存储与数据」。

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 保存工作区 | 工作区行的「保存」 | 存到 `settings\workspace.json` |
| 载入工作区 | 工作区行的「载入」 | 显式点击才载入，不会自动发生 |
| 导出设置 | 「导入 / 导出设置」行的「导出…」 | 生成备份文件，不含密钥 |
| 导入设置 | 「导入 / 导出设置」行的「导入…」 | 覆盖同名设置，重启后生效 |

导出备份不包含 AI 的 API Key、登录状态与搜索 App ID，这三类凭据整份排除。导入不会清掉本机
现有密钥。工作区只保存各页正在编辑的内容（表达式、模式、视野、代码），不保存计算结果。

## 8. 复核

本文的引擎对照命令在仓库根目录执行，需要引擎产物 `probe_call.exe`：

```powershell
& MF_Mathematics\build\bin\Release\probe_call.exe simplify_polynomial '{"expr":"x^2 + 2*x + 1"}'
& MF_Mathematics\build\bin\Release\probe_call.exe expr_eval '{"expr":"x^2-4","x":3}'
```
