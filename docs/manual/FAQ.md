# 常见问题

> 本文回答：常见问题，每条有依据。
> 排障步骤见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)，功能全表见 [FEATURES.md](FEATURES.md)，
> 产品说明见 [README.md](README.md)。

## 1. 为什么有些积分算不出来？

因为它们的原函数确实不是初等函数。软件对 `∫xˣ dx`、`∫sin(x)/x dx`、`∫e^{−x²}dx` 这类式子返回
「未实现」，而不是硬凑一个式子。这是刻意的设计选择：错误的原函数比「未实现」危害更大。初等
函数照样算得出，例如 `∫cos(x)³ dx` 返回 `(-1/3)*sin(x)**3 + sin(x) + C`。

## 2. 「未实现」和报错有什么区别？

「未实现」不是错误，信封是 `isError:false`，展示层把它当结果渲染。报错走 `isError:true`，来自
非法输入，例如不认识的拓扑空间名会返回「不认识的拓扑空间」。看到报错要分类：参数没给全、引擎
没有这个函数、还是环境没准备好。

## 3. 为什么界面不算数？

因为结论只能有一个来源。前端只做参数构造、传输与展示，一切数值来自 C++ 引擎。若前端也能算，
同一问题就有两个来源，两者不一致时用户无法判断哪个对。这条有端到端用例守着。

## 4. AI 会不会算错？

AI 不承担计算，只能调引擎。系统提示写死「所有计算由 C++ 引擎完成」，工具只有 `engine_find` 与
`engine_call` 两个，只能走引擎桥。「查看步骤」显示的是这一轮引擎调用的记录，不是模型编的步骤。
界面保证结果区是引擎的值，不保证模型正文每一句都对。

## 5. 为什么有的模式写着「（未接入引擎）」？

那个模式不在界面模式表里，前端没有它的函数映射，所以算不了。这种「引擎有、页面选不到」的
中间态不许静默。要调这些函数，用「工具 → 函数工具箱」，它列出全部 424 个引擎函数。

## 6. 断网还能用吗？

能，但有边界。断网后本地计算、绘图、教程、控制台照常；只有联网搜索、账号与 AI 需要网络。
更新检查默认关闭，不会在启动时联网。离线不影响算，只影响取外部东西。

## 7. 哪些功能必须联网？

联网搜索、AI 助手、账号登录与续期需要网络。其中账号的「记住我」与静默续期依赖站点侧部署，
站点未部署前对着线上不生效。控制台的两个组件包也需要下载，但包在站点侧尚未上传。

## 8. 为什么崩溃不上报？

这是隐私上的默认。崩溃与前端异常只写本地日志，只有用户主动导出诊断包才会交出去。代价是作者
看不到线上崩溃分布，需要用户报障时导日志。

## 9. 日志和诊断包在哪？

日志在 `%LOCALAPPDATA%\MFMath\logs`：常规日志 `app.log`（单文件上限 2 MB），崩溃日志
`crash-*.log`（含 `app.log` 尾部 200 行，只留最近 20 个）。诊断包在「设置 → 存储与数据 →
导出诊断包」生成，跳过凭据文件。发给别人前注意：诊断包会带上你的 AI 会话原文。

## 10. 我的密钥存在哪？

同一设置目录里两种待遇：登录 token 与 Wolfram App ID 用系统加密（DPAPI）存储；AI 的 API Key
以明文存在 `settings\ai.json`。DPAPI 只在当前用户下可解、失败不降级成明文落盘。

## 11. AI 的 Key 为什么是明文？

因为 AI 请求由页面直连服务商端点，密钥以明文写入 `ai.json` 的 `apiKey` 字段。代价如实写明：
明文落盘、常驻页面内存。界面文案如实说明「没有加密」。删除设置文件不会删掉对应的 `.bak` 备份，
共享机器上要彻底抹掉需手工删除 `settings\ai.json.bak`。

## 12. 换了宿主要重填密钥吗？

只有 AI 这一项要重填。搜索、账号、更新、窗口、工作区、历史的字段同名、格式相同，能跟着走。
AI 的密钥不能：旧宿主写的是 DPAPI 密文，新宿主读的是明文，两种形式互不通用。

## 14. 支持哪些系统？

Windows 10 / 11（64 位），运行时需要 WebView2（Win11 自带，Win10 需安装）。构建需要 CMake、
Visual Studio C++ 工具链、vcpkg、Node.js 与 Rust。非 Windows 平台没有构建或验证记录。

## 15. 能装吗？安装包验证到哪一步了？

能装。安装器是自写程序（`MFMath.Installer/`），一条命令出包：

```powershell
.\MFMath.Installer\tools\build-setup.ps1
```

产物 `MFMath.Installer\target\release\Multifunctional-Mathematics_<版本>_x64-setup.exe`（约 18 MB），
向导里可选安装位置、是否建桌面快捷方式、装完是否运行；每用户安装、不请求管理员权限，装到
`%LOCALAPPDATA%\Programs\Multifunctional-Mathematics\`，卸载入口在「设置 → 应用」，卸载默认保留
`%LOCALAPPDATA%\MFMath` 里的用户数据。

验证到哪一步：「安装 → 启动 → 卸载」已在 Windows 11 本机跑通（装完主程序自检 5/5，卸载后目录、
快捷方式、注册表项全清）。**未验证**的是其它 Windows 版本、高 DPI 缩放下的界面观感，以及全新机器上
缺失 WebView2 时真引导程序那一支。

用户会遇到的一件现实：安装包**未签名**，首次运行会被 SmartScreen 拦一下，点「更多信息 → 仍要运行」。
签名接口已就绪，缺的是证书。详见 [INSTALL.md](INSTALL.md) 与
[INSTALLER.md](../../MFMath.Host.Rust/docs/INSTALLER.md)。

## 16. 我的数据存在哪？

根是 `%LOCALAPPDATA%\MFMath`：设置文件在 `settings` 子目录（历史、工作区、AI 配置、搜索、账号、
更新等），日志在 `logs`，组件在 `components`。外观与界面语言存在 `localStorage`（`mf_` 前缀）。

## 17. 怎么把配置迁到另一台机器？

用「设置 → 存储与数据 → 导入 / 导出设置」。备份包含设置文件与外观偏好，不含凭据（AI、账号、
搜索三个文件整份排除，其余文件按字段名再剥一遍）。导入不清掉现有密钥，坏包在写第一个文件之前
整包拒绝。导入后要重启才生效。

## 18. 为什么有时候算得很慢？

慢分两类：算法本身没优化完，或输入规模本来就大。大规模病态输入已改成按上限明确拒绝并解释原因，
所以现在多数是快速报错而不是卡住界面。仍会慢的清单见 [../HANG-OPTIMIZATION.md](../HANG-OPTIMIZATION.md)，
重活走后台通道并显示进度。

## 19. 算太久能取消吗？

能停止等待，但引擎不会被叫停，那一步会算完。引擎没有取消钩子，宿主只能停止等待并丢弃结果，
所以文案是「已取消等待」。异步通道在宿主没有后台通道时自动退回同步调用。

## 20. 为什么同一功能有时弹参数窗口、有时不弹？

判据只有一条：这个模式有没有登记参数表。登记了就先弹「输入参数」框收参数；没登记就直接在
输入框里算。「同一个功能」常常是同一个引擎函数下的两个不同模式，一个有参数表一个没有。

## 21. 输入框里的分号是干什么的？

是参数分段符。深度 0 的分号把输入切成多段，一次喂多个参数，例如 `x^2-4; -2; 2`。缺必填参数时
界面直接拒绝调引擎并说明缺什么，不会静默填默认值。

## 22. 界面语言为什么只翻了一部分？

因为多语言是逐步扩大的。导航、顶栏与 14 个学科视图已中英双语，可在「设置 → 外观 → 界面语言」
切换并记忆；页面正文与教程正文仍是中文。UI 语言与 AI 的回答语言是两件事。

## 23. 计算需要 Python 后端吗？

不需要。计算全部在 `mf_mathematics.dll` 里完成，界面、控制台与 AI 助手都只调这一个引擎，
程序不附带 Python 计算后端，也不需要 Python 运行环境。控制台里的 Python 是可选的编程组件，
用于写脚本调用同一个引擎，与计算实现无关。

准确性测试资产单独保留，可对任意引擎 DLL 运行。它不在本仓库，位于相邻目录
`../Multifunctional-Mathematics/MF_Mathematics/tests/accuracy/`，含 28 个 `.py` 与 `report.json`、
2180 条用例，用独立参考实现对拍。跑法：`python run_accuracy.py [域] [--coverage] [--json <文件>]`；
被测 DLL 由 `harness.py` 的 `ENGINE_DLL` 决定，可用环境变量 `MF_ACC_DLL` 覆盖。

## 24. 引擎有多少函数？

424 个已注册函数，全部可由界面、控制台与 AI 助手调用。这个数由 `probe_call.exe list_functions`
得出，是构建守门值，随引擎新增函数变化。
